# Course map — Mathematical Tools: Units, Vectors, and Coordinates

This is course-02, a complete topical course for high-school seniors: seven 55-minute lessons and two 55-minute capstone periods, 495 minutes total. The entry capabilities are signed arithmetic, fractions, ratios, integer powers, simple linear equations, and reading coordinate graphs. Course-01 supplies the habit of distinguishing inputs and evidence from derived claims; Lesson 01 restates this bridge so no inaccessible prior artifact is needed for core arithmetic.

The course uses synthetic 2D examples throughout. No prior trigonometry, university linear algebra, calculus, or physics is assumed. Lessons teach right-triangle ratios and vector normalization before projections, then substitution before a general inverse. Advanced source terminology is recognition-only. Units 1, 2, and 3 end after Lessons 02, 04, and 07 respectively.
