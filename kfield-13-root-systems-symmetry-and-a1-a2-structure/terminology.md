# Terminology and notation

All core coordinates are dimensionless. Symbol roles are local and explicitly declared. No physical units are inferred from these examples.

| Term | Definition |
|---|---|
| carrier | Declared collection on which a rule acts; changing it changes the claim. |
| tuple | Ordered list; its positions retain their identities. |
| composition FG | Apply G first, then F. |
| I,R,T | Identity; pair swap; triple cycle T(x,y,z)=(z,x,y). I here is not a physical tensor. |
| inverse | Rule that restores every input on the stated carrier. |
| closure | Every composition stays inside the specified operation set. |
| invariant | Specified quantity unchanged by an operation. |
| group | Closed operations with identity, inverses and associative composition. |
| Z, congruence, mod n | Integers; equal remainder means the difference is divisible by n. Chosen remainders are 0 through n-1. |
| C_b,C_c | Ordered signed integer carry coordinates; dimensionless. |
| S,A | C_b+C_c and C_b-C_c; inverse halves require equal parity. |
| P₁,Q₁ | Integer A weight carrier Z and even transfer displacement lattice 2Z. |
| quotient / class | Grouping by allowed displacement; not a replacement for the full input. |
| r,k in A=r+2k | Remainder 0 or 1 and retained integer displacement coefficient. |
| e₁,e₂,e₃ | Formal channel basis of dimensionless triple space. |
| H | Real zero-sum plane x+y+z=0. |
| α₁,α₂ | Simple roots (1,-1,0),(0,1,-1). |
| root / root lattice Q₂ | One of six unit transfers / all integer zero-sum triples. |
| dot product / squared norm | Sum of matched products / v·v in abstract Euclidean channel space. |
| Cartan C_ij | 2(α_i·α_j)/(α_j·α_j); not a carry C_b. |
| h, μ | Common mean vector (1,1,1)/3 for channel centering; general scalar mean retained for reversal. |
| u_i, P₂ | Centered weights e_i-h; all integer combinations a u₁+b u₂. |
| weight class | Remainder of a+b mod 3; all three displayed u_i have class 1. |
| ρ,v,ℓ | Address residue, balanced digit, compatible lift ℓ=ρ+3v at n=1; v elsewhere can mean a generic vector explicitly declared locally. |
| family tag | Independent typed identifier, illustrated by synthetic F2. |
| ray and scale | Ratio coordinates with declared positive-scale/oriented convention; retain scale and sign convention. |
| detector parity | Sign of a signal under a declared antipodal map, when that signal has definite parity. |
| matrix / transpose | Row-rule array / rows and columns exchanged. |
| action / intertwiner | Composition-consistent transformations / map f with f(Tv)=U(f(v)). |
| M_cell,R_cell,G_phase,O_K,B | Reserved source symbols: Cell3 Gram metric, its inverse, phase metric, origin and locked ordered basis. They are not used for the abstract dot product. |
| evidence scope | Source report, finite derivation, synthetic illustration, interpretation or unresolved physical mapping; never silently promoted. |
