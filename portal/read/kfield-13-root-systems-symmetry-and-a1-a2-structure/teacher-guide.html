Teacher guide

This course teaches a finite A1/A2 transfer atlas to high-school seniors. It uses the approved six-lesson order and nine core 55-minute periods, plus two capstone periods. Lessons 02–04 each have two periods because inverse coordinates, plane geometry, and quotient classes need separate practice. The lesson files include answers; conceal answer sections during independent work, then reveal them for correction.

Entry capabilities are signed arithmetic, fractions, powers, linear equations and coordinate graphs. The series lists courses 09, 11, and 12 as prerequisites, but this course explicitly reintroduces tuples, composition, carries, congruence, dot products, basis coefficients, and matrix actions. No unprovided theorem from those courses is assessed. Ask students to compute (-2)², (3-(-1))/2, and solve x+y=0 for y; answers 4,2,-x. Repair these immediately before lesson 01 if needed. A longer arithmetic intervention may require extra time beyond the core schedule.

Each core period allocates 5 minutes retrieval, 20 instruction/worked example, 15 practice, 15 diagnostic checks and repair. For two-period lessons divide the exposition at the stated focus, reuse the worked example for the first component in period A and its quotient or metric analysis in period B, and split practice before diagnostics. Do not deliver all new terms in one opening lecture. Students should explain calculations aloud in pairs before seeing the answer.

At the end of lesson 02 (unit I), check the difference between a symmetry of the sum and a symmetry of the squared norm. A fixed S allows one compatible parity, not both. At the end of lesson 04 (unit II), check root versus lattice point versus weight versus class. At the end of lesson 06 (unit III), require the student to point to each carrier in the typed record and identify the missing map in a physical claim. These are cumulative dependency gates, not extra unexplained assessments.

If a student treats negative remainders incorrectly, use -5=1+2(-3) and -1=2+3(-1). If a student equates three weights to three classes, calculate u₂-u₁ explicitly. If a student says every lift is zero-sum, use v=(1,1,1). If matrix notation is slowing progress, have the student perform the coordinate rule first and then match each row to that operation. All these repairs are taught examples, not extra theory.

Use the abstract Euclidean metric only for roots. Do not replace M_cell or any source physical metric with the identity matrix. No physical cell constants, rounding operations, or measured datasets are required. The general source invariants remain in input-contract.json; out-of-scope claims are not borrowed as premises. Keep color-first C₃ direct-sum W₂ ordering if discussing later courses; a weak-first ordering requires an explicit permutation. That later carrier is recognition-only here.

Evidence discussion should distinguish source assertions from calculations students can verify. Read sources.md with advanced students: archival branch closure status is a source report, and the integration namespace is separate. Physical identification is an open mapping problem, not an error in the finite calculations. No experiment, global-form selection, or compiler typecheck is claimed. Do not require those extensions on the capstone.

Every reduction in this course is reversible with retained fields. When marking, ask “what would recover the input?” rather than accepting a lone class label. Keep mistaken intermediate student records with the correction so the discrepancy remains interpretable. No observation is discarded because it disagrees with an expected pattern.

The executable verification script uses exact rational arithmetic and finite enumerations. It supports the answer key; it does not replace teaching review. The deterministic course validator checks files, hashes, dependencies, assembly identity and audit consistency, not pedagogical truth. See audit_report.json for actual content review and any repairs.
