Start with a course in the order below, using its teacher guide for entry skills and pacing. The full sequence is a multi-term curriculum; a lesson can span several class periods.

Teaching pathways and assessment guidance explains how to select a sequence with all its prerequisites and use the course materials.

Each complete course includes student lessons, worked answers, a teacher guide, glossary, capstone and rubric, source provenance, mathematical checks, and audit records. Observations, mathematical deductions, proposed mechanisms, and unresolved source branches retain distinct labels.

Production uses the user-approved project output location. Ordinary course writes stay inside the assigned project workspace. Original checkpoints and earlier working artifacts are retained for recovery.
